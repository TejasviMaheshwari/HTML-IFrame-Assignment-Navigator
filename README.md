# HTML IFrame Assignment Navigator

## 📌 About the Project

The **HTML IFrame Assignment Navigator** is a simple web development project created using HTML and CSS. It provides a sidebar containing buttons for different assignments and an iframe that displays the selected assignment within the same webpage.

This project demonstrates how iframes and HTML links can be used together to create a basic navigation interface.

## ✨ Features

* Sidebar navigation for multiple assignments.
* Displays selected assignments inside an iframe.
* Simple and clean layout using CSS Flexbox.
* Styled navigation buttons with rounded corners.
* Opens linked pages within the main content frame.
* Basic HTML and CSS implementation.

## 🛠️ Technologies Used

* **HTML5** — Structure and iframe implementation.
* **CSS3** — Styling, layout, colors, and Flexbox.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click an assignment button in the sidebar to load the linked page in the iframe.

## 📚 Concepts Learned

* Working with HTML iframes.
* Using anchor tags with the `target` attribute.
* Creating layouts with CSS Flexbox.
* Styling navigation buttons.
* Organizing and navigating between multiple HTML pages.
